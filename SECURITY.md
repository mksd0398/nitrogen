# Security

## Reporting a vulnerability

Report it privately through GitHub: on the
[Security tab](https://github.com/mksd0398/nitrogen/security/advisories/new),
choose **Report a vulnerability**. Please do not open a public issue.

Include the Nitrogen version, which part is affected (the CLI, or the
generated app's functions or pages), and the steps that show the problem.
The maintainer replies in the report.

## Supported versions

Only the latest release on npm gets fixes. A fix to the templates reaches an
app you already generated only if you apply it there: the changelog says
which files to change.
