# Gadget wind-down: launch content

Gadget [announced it is shutting down](https://gadget.dev/blog/gadget-wind-down).
Apps run until March 31, 2027, no new apps can be started, and first-time production
deploys close at the end of November 2026. This folder is the content for reaching
Gadget users who are deciding where to move.

| File | What it is |
|---|---|
| [migration-guide.md](migration-guide.md) | The anchor article. Every other post links here. Ready for dev.to, Hashnode and Medium (canonical URL set). |
| [reddit.md](reddit.md) | Posts for r/shopifyDev, r/shopify, r/Firebase, r/SaaS, plus a comment template |
| [github.md](github.md) | Pinned Discussion, issue template, topics, release note |
| [social.md](social.md) | Show HN, X thread, LinkedIn, Discord, Shopify forums, and a posting schedule |

Facts about Gadget come from its announcement as relayed in team chat; the post
itself wasn't fetched while these were written. Check the dates against
<https://gadget.dev/blog/gadget-wind-down> before posting, and update step 4 of the
guide once Gadget publishes its migration tools.
